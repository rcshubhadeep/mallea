## User acceptance target

Right-click Brief input, choose Set Automation, pick When I type, define Muse concept extraction, choose Concepts list and Replace, inspect summary/permissions, enable. Write/change text, pause and observe a new result. Permit a recipient Surface in another app to use output, then revoke it and verify subsequent operations block. Existing source/destination data is not retroactively erased. Independently test saved-design auto-sync retaining review feedback.

## Exclusions

Only approved local-host apps. No general graph editor, multiple transformer chains, cron/background autonomy, remote encryption/P2P or Observer. Date/slots and other variations are optional capability probes, not additional required polished apps. Model reasoning and deterministic execution remain clearly distinguished.

Do not claim E4 complete until real Muse execution and Surface-level permissions pass, even if wizard UI looks complete. Protect E005 recording time; cut optional examples before accepted core behavior.
